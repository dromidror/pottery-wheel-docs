# Units & measurements

*What you'll learn: how sizes are shown and set.*

- Internal sizes are millimetres; the UI can display **mm** or **inch** (see
  [Settings](../files/settings.md)).
- The editors show dimension ticks (cm) for reference.
- **Wall thickness** is a global setting used for hollow walls, galleries, and export.

!!! warning "Wall thickness vs print"
    Set a realistic wall thickness for your clay/printer; it affects both the on-screen wall
    and the exported STL.
