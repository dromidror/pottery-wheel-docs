# Glossary

*Terms used throughout this guide.*

**Profile**
: The 2D outline (silhouette) of a piece that is revolved around the axis to form the 3D body.

**Profile editor**
: The screen where you shape the profile by dragging points.

**Axis**
: The central line the profile revolves around. It can be straight or a **curved axis**.

**Curved axis**
: A bent center line that makes asymmetric or leaning forms instead of a perfectly round body.

**Cross-section**
: The shape of a part's wall as seen across it — round by default, and editable (e.g. to
flatten a handle).

**Part**
: A component of a piece — body, handle, lid, knob, spout, base/foot.

**Template**
: A starting design (Cup, Mug, Bowl, Teapot, …) you build from instead of starting blank.

**Connection**
: The rule that joins one part to another, such as **Top+Bottom → Surface** for a handle.

**Gallery**
: An interlocking ledge/flange so a lid seats correctly on the body.

**Lid / knob**
: A cover for an opening and the grip on top of it.

**Stamp**
: A decoration applied to the surface — either **text** or an imported **STL relief**.

**Relief**
: A 3D decoration (sprig) imported from an STL file and wrapped onto the surface.

**Raised / recessed**
: A stamp that stands out from the surface (raised) or is pressed into it (recessed).

**STL**
: A standard 3D mesh file format used for 3D printing and for exchanging models.

**Prototype**
: The exported STL of the ware itself, ready to print.

**Mold**
: A single-stage casting mold — the negative used to slip-cast the piece.

**Negative mold**
: A master for **2-stage** casting: print it, cast plaster working-molds, then slip-cast.

**Keys**
: Alignment features on mold parts so they register together accurately.

**Reservoir**
: The pouring funnel/basin on a casting mold.

**Shrinkage**
: The size reduction of clay as it dries and fires — allow for it when scaling molds.

**Slip casting**
: Pouring liquid clay (slip) into a plaster mold to form a piece.
