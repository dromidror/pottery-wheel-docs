# Install & open

*What you'll learn: how to get and open the app on each platform.*

=== "Android"
    1. Install the app (APK / store listing — link TBD).
    2. Open it; it starts with a simple default shape.

=== "macOS"
    1. Open **Pottery Wheel.app**.
    2. If the window is closed, use **File ▸ New** / **Open** / **New from Template** to
       bring it back — the app keeps running in the Dock.
