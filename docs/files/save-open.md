# Save & open

*What you'll learn: save, open, and share projects.*

Projects are saved as **JSON** (the same format on both apps), so a project made on one
platform opens on the other.

=== "Android"
    **Save** / **Open** use the system document picker — choose any filename and location.
    "Save" suggests a `.json` name.

=== "macOS"
    **Save** / **Open** use the standard Save/Open panels. If the window was closed,
    **New/Open/New from Template** reopen it.

!!! note
    Older files may use the `.pottery` extension; they still open. New saves use `.json`.
